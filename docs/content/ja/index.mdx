<Section
  title="間違ったリクエストはサーバに届かない"
  lede="リクエストはコードが生成される前に仕様と突き合わされます。書いている最中のエディタで、ビルド時に、そして指定すれば実際のサーバに対しても。綴りを間違えれば、意図した名前が返ってきます。"
>

```ansi
requests/BadQuery.jmap.json: methodCalls[0].arguments.filter.hasAttachmnt: EmailFilterCondition has no property "hasAttachmnt"
	did you mean "hasAttachment"?
requests/BadQuery.jmap.json: methodCalls[1].arguments.#ids.name: the referenced call is Email/query, but the reference names Email/get
	call "c0" invokes Email/query
```

</Section>

<Section
  title="3つの言語に対応し、依存は最低限"
  lede="ランタイムはライブラリとして配られるのではなく、リクエストと一緒に生成されます。プロジェクトが抱えるのは生成されたディレクトリだけで、そのほかはほとんどありません。"
>

<Traits>
  <Trait title="Go" lang="go">
    生成されたパッケージは標準ライブラリしか使いません。通信はすでに手元にある
    `http.Client` です。
  </Trait>
  <Trait title="Rust" lang="rust">
    `serde` と `serde_json` だけです。HTTP スタックも TLS バックエンドも async
    ランタイムも付いてきません。通信は、プログラムがすでに使っているクライアント
    の上に実装する `Transport` です。
  </Trait>
  <Trait title="TypeScript" lang="typescript">
    依存はありません。プラットフォームに求めるのは `fetch` だけです。
  </Trait>
</Traits>

</Section>

<Section
  invert
  title="ラッパーではなく、コンパイラであること"
  lede="次の5つは、どれもこの違いから導かれます。"
>

<Traits>
  <Trait title="独自の API がない">
    リクエストファイルは JMAP そのものです。覚えるのは仕様であり、3つの言語で
    同じ知識が通用します。
  </Trait>
  <Trait title="訊いたとおりの形で返る">
    結果はリクエストが要求したプロパティだけを持ちます。ひとつ増やせば型が育ち、
    存在しないものを要求すればビルドが止まります。
  </Trait>
  <Trait title="JMAP が報告するすべての層のエラー">
    リクエスト全体の失敗、メソッド呼び出しの失敗、200 を返しながら拒否している
    /set。生成されたコードがこれらを区別するので、呼び出し側は区別せずに済みます。
  </Trait>
  <Trait title="プッシュとページングはループとして">
    watch を指定したリクエストは、サーバが報告する変更を追い続けます。paged を
    指定したリクエストは、一部ずつ返る結果を最後まで読み通します。
  </Trait>
  <Trait title="まわりの道具">
    実際のサーバにリクエストを送るコマンド、自分のコードをテストするための JMAP
    サーバ、そして jmapc がまだ知らないケイパビリティを書くスキーマファイル。
  </Trait>
</Traits>

</Section>
